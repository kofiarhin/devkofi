# Project Operating Guide

## Product

Summarize the product, customer, problem, and current goal from the PRD.

## Working rules

- Read the PRD, roadmap, review standard, relevant context, and current repository evidence before changing work.
- Keep one ticket to one outcome and one reviewable change.
- Preserve unrelated work and existing project conventions.
- Distinguish proposed, implemented, verified, merged, and deployed states.

## Permissions

Define safe/read-only, approval-required, and human-owned actions for this project.

## Completion
